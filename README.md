# 精读钥匙 · CloseRead

**把自己的文章，变成可以逐句学习的精读材料。**

读懂翻译，不等于理解一句话如何成立。CloseRead 从真实的自学需求出发：保留原句，把词语、表达和语法放回句子里解释，再用小练习和笔记留下自己的理解。

它不是固定课程，也不是聊天窗口。你带来材料，决定这次要学的段落；本地版使用你自己的 API，把材料整理成可保存、可继续阅读的精读页面。

> v0.1 发布候选，尚未公开上线。作者：[yiliabuilds](https://github.com/yiliabuilds)。

## 一条清楚的学习路径

导入 Word 或粘贴文本 → 选择段落 → 分批生成 → 按句阅读 → 练习与笔记 → 下次继续。

## 功能

- **导入与选段**：粘贴文本或导入 .docx（最大 5 MB）；生成前可编辑、可只选这次要学的段落，单次 10–3000 字符。
- **逐句精读**：每句原文之下是英语讲解与可展开的中文辅助。词语和语法放回句子里讲，不拆散成独立的功能页。
- **练习与笔记**：生成内容包含练习与参考答案；笔记和阅读位置保存在当前浏览器，可通过“继续上次”回到保存位置。旧结果若缺少题目材料，会显示提示，不保证每道练习完整可用。
- **文章库**：生成结果保存在本机，可搜索标题与原文；独立阅读页面可同时打开不同文章，各自保留笔记与位置。
- **学习计划**：可以自动安排一周、手动调整、打开关联的外部资源网站；也可以完全不用，直接读一篇文章。
- **自己管理模型使用**：本地版使用自己的 DeepSeek API，密钥存于 macOS 钥匙串，可在设置页更换或清除；较长选段分批生成，失败停止、不自动重试。已保存的成功批次可在继续同一请求时复用；继续仍可能计费。

## 先体验，再带来自己的文章

展示版提供固定的 Lina 示例、练习笔记与学习计划，不调用付费模型，适合先了解阅读方式。完整生成能力需要本地运行，目前主要支持 macOS。

## 两种使用方式

| | 在线展示版（docs） | 本地完整版（local） |
|---|---|---|
| Lina 示例、中文辅助、练习笔记 | 支持 | 支持 |
| 学习计划与外部资源链接 | 支持 | 支持 |
| Word / 粘贴文章、AI 精读 | 不提供 | 支持，使用自己的 API |
| 账户 / 云同步 | 无 | 无 |

### 体验展示版

无需安装依赖。在项目根目录执行：

```sh
python3 -m http.server 4190 --directory docs --bind 127.0.0.1
```

访问 http://127.0.0.1:4190 。GitHub Pages 发布目录仅选择 docs，不要选择整个仓库。

### 运行本地完整版

当前主要支持 macOS；需要 Node.js（本项目以 Node 22+ 为目标）和 Python 3，无额外 npm 依赖。

1. 下载项目并解压，打开 local 文件夹。
2. 双击 启动精读.command；如无法双击，可在终端进入 local 后运行 `python3 start-local.py`。
3. 打开 http://127.0.0.1:4180 。
4. 在“我的”配置自己的 DeepSeek 密钥。密钥保存在 macOS 钥匙串，不写入 GitHub 或网页。
5. 新建精读，粘贴原文或导入 .docx，勾选段落后生成。

关闭启动程序会停止服务。端口被占用时先关闭旧实例；请勿将该单用户本地服务直接暴露到公网。

## 当前边界

- .docx 最大 5 MB；单次选段 10–3000 字符，生成按批处理。
- 默认模型配置见 local/server.mjs；服务商模型可用性和收费以自己的账户为准。
- 英语讲解、按需展开中文辅助。生成结果可能有误，不是评分或语言能力认证。
- 当前主要验证德语初学场景；其他原文语言选项不代表均已验证教学质量。
- 页面包含移动端适配，尚未完成全面真机测试。
- 暂无 PDF/OCR、网址抓取、听写、账号、多端同步。
- 在线示例不是实时 AI 输出；展示版不能上传私人文章或配置密钥。

## 数据与隐私

- 本地文章、批次缓存和失败诊断保存在 local/.local-data，均不应提交。
- 笔记、阅读位置、计划保存在当前浏览器。清除缓存或换浏览器可能失去这些记录。
- 阅读页导出精读/练习；计划工作区导出备份。两类数据需分别备份。
- 主动生成会把所选文本发送给模型服务，可能计费。不要提交敏感或无权使用的材料。
- 在线展示版仅含固定示例与浏览器本地数据，无分析统计或付费模型请求。
