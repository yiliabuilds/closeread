精读钥匙v0.1 展示版

先体验，再用自己的文章。

精读钥匙 · CloseRead 帮助语言初学者逐句阅读：原句在前，英语解释在下，需要时展开中文辅助，再用小练习把表达变成自己的。

现在可以体验什么？

认识 Lina →：目录跳转、英语讲解、中文辅助、练习笔记、继续阅读与导出。

学习计划 →：自动安排一周、手动调整任务、打开外部学习网站。不会调用 AI。

你的数据在哪里？

展示版的笔记、阅读位置和计划只保存在当前浏览器，不上传服务器。换设备不会自动同步；清除网站数据后可能丢失。阅读页可导出练习，计划工作区的“设置与备份”可导出计划数据。

完整本地版

本地版支持粘贴文本、导入 .docx、选择段落、使用自己的 DeepSeek API 生成逐句精读，并保存结果。当前单次选择 10–3000 字符，长内容分批处理；暂不支持 PDF、网页抓取或听写。

目前主要支持 macOS，需要 Node.js 和 Python 3。在项目下载包的 local 文件夹中运行启动精读.command，再打开 http://127.0.0.1:4180。首次在“我的”配置自己的密钥。

本地版的文章保存在本机文件夹，笔记和计划保存在浏览器；请分别备份。只有主动点击生成时，选中的原文才发送到模型服务并可能计费。不要输入敏感材料。

打开 CloseRead 项目仓库 ↗，点击 Code → Download ZIP 下载本地版；安装步骤见仓库 README。此页面不会要求你填写 API 密钥。

关于本项目

这是个人项目的 v0.1，不是完整课程或自动评分工具。AI 生成内容可能有误，需要核对；固定示例只代表当前教学风格。
