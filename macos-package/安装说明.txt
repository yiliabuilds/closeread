精读钥匙 · CloseRead v0.2.3
适用于 Apple Silicon（M 系列）Mac，macOS 15 或更新版本。

1. 将 CloseRead 拖入 Applications（应用程序）。
2. 关闭原来的精读启动程序，然后从应用程序打开 CloseRead。
3. 首次启动选择「导入原有文章」，选择原 german-learning-os 文件夹；将复制其中 .local-data，原数据不动。
4. 使用原来的浏览器打开 http://127.0.0.1:4180/index.html，保留原有笔记和生词。默认浏览器不同时，请在原浏览器手动打开此地址。
5. 退出时在 Dock 中退出 CloseRead，或按 Command-Q。关闭网页不会退出后台服务。

数据保存在 ~/Library/Application Support/CloseRead/data。更换应用不删除此目录。
密钥继续使用 macOS 钥匙串，首次访问可能需要系统授权。
本包只含程序，不含私人文章、笔记或 API 密钥。无需安装 Node.js 或 Python。

此版本为个人使用，使用本机临时签名，未经过 Apple Developer ID 签名或公证。
